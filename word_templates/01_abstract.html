ABSTRACT

“Academia Portal” is a web-based application that is used to retrieve information from websites of different universities. Users such as students make use of the internet for study purposes and to get other necessary information from different universities. Currently there is no application that provides all the information related to universities on one platform. Students visit each university website manually, which may consume too much time for finding a specific query. The Academia Portal overcomes this problem by providing answers to the student’s query on one platform. These queries are answered by retrieving information from different universities of Rawalpindi and Islamabad.

Academia Portal helps the user to get all necessary information and also performs comparison on the basis of different criteria selected by a student. The architecture of Academia Portal is based upon a web mining technique. The first part of the web-based application is data extraction according to user query. This data extraction is performed by means of a crawler and by using Document Object Modeling (DOM) library. After data extraction, data is filtered by using different filtration techniques for desired output and then stored into the database. Finally, data is retrieved from the database and the required result is displayed according to user query.

The developed application is tested using unit testing and system testing on different platforms such as personal computers and mobile phones. Different test case scenarios are designed that verify the functionality of the application. The performance of the web-based application is found correct as per the designed specification. The Academia Portal is developed in PHP and by using Microsoft SQL Server Management Studio.
